# WebProj: 3D Space

## Overview

This repository contains a front-end web application that implements a 3D space environment.

## Project Structure

The application is contained within a `WebProj` directory and consists of three primary files:

* `3dSpace.html`: The main structural document and entry point for the web page.


* `styles.css`: The cascading stylesheet used for the visual layout and design.


* `script.js`: The JavaScript file handling the application logic and interactive elements.



## Getting Started

To run this project locally, no complex build steps or external dependencies are required.

1. Ensure all three core files (`3dSpace.html`, `styles.css`, and `script.js`) are extracted and kept together in the same `WebProj` directory.


2. Open the `3dSpace.html` file directly in any modern web browser.



## Technologies Used

* HTML5
